# A003 selective release-assurance routing task

Plan the minimum correct Skill route for the user's requested release decision using only the supplied Skill catalog.

The packet already contains a current, evidence-backed impact register that the user explicitly says is complete for this decision point. Do **not** repeat change-impact analysis.

The user does want traceability assurance, release-evidence validation, operational-readiness assessment and a consolidated solution/change-readiness handoff. The user does **not** want an ITIL assessment in this task.

Do not perform the detailed assurance work in the routing response. Return only:

1. Objective interpreted.
2. Selected Skills in exact execution order.
3. Why each selected Skill is needed.
4. Skills deliberately not selected, with reason.
5. Stop/conditional rules downstream stages must preserve.
6. Expected final artifact.

Select the minimum route. Do not invent approvals, defect closure, rollback success, monitoring thresholds, authority, test results or missing traceability.
