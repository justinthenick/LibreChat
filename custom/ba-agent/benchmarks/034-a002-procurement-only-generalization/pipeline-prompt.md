# Fixed-control procurement pipeline

Use the supplied mature procurement baseline directly. Do not redo requirements analysis, NFR analysis, solution design or ADR work.

The fixed control must execute exactly these stages in order:

1. vendor-neutral procurement specification;
2. market-expansion planning beyond the incumbent-reseller candidate set;
3. evidence-based candidate verification.

Preserve every Hard minimum / Target / Preference / Unknown distinction. Do not invent product facts, approval authority, market candidates or candidate evidence.
