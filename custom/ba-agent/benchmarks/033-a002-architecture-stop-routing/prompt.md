# A002 routing task

Plan the minimum correct Skill route for the user's technical-solution/procurement objective using only the supplied Skill catalog.

This is a routing test. Do **not** perform the detailed requirements, NFR, architecture, ADR, procurement specification, market search or candidate verification work in this response.

Return:

1. Objective interpreted.
2. Selected Skills in exact execution order.
3. Why each selected Skill is needed.
4. Skills deliberately not selected, with reason.
5. Stop/conditional rules, including any architecture-changing Unknown that makes downstream procurement premature.
6. Expected final artifact or resume point.

Do not invent products, specifications, thresholds, architecture, decision owners or approval routes.
