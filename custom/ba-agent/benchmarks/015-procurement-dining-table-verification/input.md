# Benchmark 015 — Apartment Dining Table Procurement Verification

## User objective

Buy a dining table for a narrow apartment dining area. The table must seat six adults, fit the room and building access constraints, and stay within budget.

The user wants a recommendation **only where the supplied evidence is strong enough to buy confidently**. Do not browse the web; assess only the evidence packet below.

## Requirements

### Hard gates

- **H-01 — Landed budget:** table plus stated mandatory freight must be no more than **A$650**.
- **H-02 — Seating:** the exact table/configuration must be documented as suitable for **six adults**.
- **H-03 — Room width:** assembled tabletop width must be **no more than 90 cm**.
- **H-04 — Room length:** assembled table length in the intended six-seat configuration must be **no more than 180 cm**.
- **H-05 — Building access:** the table must be supplied disassembled/flat-pack, with no individual rigid component wider than **78 cm**, because the final internal doorway cannot accept anything wider.

### Preferences

- **P-01:** solid timber or timber veneer is preferred over plain laminate.
- **P-02:** warranty or returns are preferred.
- **P-03:** lower landed cost is preferred after hard gates are satisfied.
- **P-04:** a non-extendable six-seat setup is slightly preferred because the room is narrow.

## Important benchmark boundary

Do not assume specifications not present in this packet. In particular:

- a family offering a six-seat variant does not prove that an ambiguous listing is that variant;
- “flat-pack” does not by itself prove that every rigid component satisfies the 78 cm access limit;
- approximate seller dimensions and “should fit” statements are not exact measurement evidence.
