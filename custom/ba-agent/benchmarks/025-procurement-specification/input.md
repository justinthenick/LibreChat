# Benchmark 025 Input — Meeting-Room Display Procurement Handoff

## Objective

Equip one meeting room with a large display suitable for presentations and video meetings. The solution must work with the room's existing laptop-dock workflow and wall location.

## Accepted solution/design evidence

- The room already has a dock with one available HDMI output. Replacing the dock is out of scope.
- A single wall-mounted display is required.
- Minimum screen size explicitly approved: **70 inches**.
- The room owner would **prefer approximately 75 inches** if it fits the wall and budget.
- Native 4K resolution is a **Target**, not a mandatory minimum.
- The display must accept the existing dock's HDMI output.
- Wireless casting is **preferred**, but the project may proceed without it.
- Built-in speakers are acceptable; an external audio system is not part of this procurement.
- The available wall width is 1.85 metres. Exact bezel/overall display dimensions must therefore be checked against the candidate product.
- Wall construction is suitable for a commercial display mount, but the required VESA pattern and final mount model are **Unknown** until the display is selected.
- Budget aim: **A$2,500 including display and mount**. This is a **Target**, not a hard cap.
- Commercial signage features, touch input and integrated camera are not required.
- Brand is open.
- Project lead mentioned Samsung and LG only as examples seen in other rooms; no brand decision has been made.
- Installation labour is out of scope for this purchase.

## Request

Prepare a vendor-neutral procurement specification suitable for downstream market expansion and product verification.
